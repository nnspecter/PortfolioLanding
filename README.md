# Данил (nnspecter) — Portfolio & B2B Landing Page

> Минималистичный, высококонверсионный лендинг Fullstack-разработчика и инженера AI-систем.
> Реализован в строгом соответствии с дизайн-системой `Design.md` (Inter Typography, 2D High-Clarity Surface, Zig-Zag Layout, No Clutter).

---

## ⚡ Архитектура и Дизайн (согласно Design.md)

- **Типографика:** `Inter` (Display: 700 с плотным трекингом `-0.04em` ... `-0.06em`, Body: 400 16px/1.6 max 72ch). Моноширинный шрифт: `JetBrains Mono`.
- **Цветовая палитра:** Глубокий off-black (`#0A0A0A`), четкие поверхности (`#121214`), контрастные 1px границы (`#26262B`), сдержанные акценты без перенасыщенности.
- **Сетка и геометрия:** Радиус скругления строго `8px` (`0.5rem`). Максимальная ширина контейнера `1280px` с боковыми отступами `1.5rem`.
- **Компоновка Hero:** Split-screen (продающий текст слева, техническая спецификация архитектуры справа).
- **Секции кейсов:** Чередующиеся строки **Zig-Zag** (текст + спецификация) без шаблонных 3-колоночных сеток.
- **Чистота интерфейса:** Полный отказ от эмодзи, перегруженных виджетов и AI-штампов. Только факты, цифры и архитектурные решения.

---

## 💼 Продающие преимущества из резюме

1. **Meta Technology Provider:** Официальный статус интегратора после успешного прохождения технического и правового аудита Meta Platforms (WhatsApp Business, Instagram Direct, Threads, HMAC-SHA256, OAuth 2.0).
2. **AI-агенты и кратное сокращение ФОТ:** Омниканальное единое окно + гибридный ассистент на базе LLM с модулем Speech-to-Text (STT) для голосовых сообщений. Автоматизация 70% первичного контакта 24/7.
3. **Feature-Sliced Design (FSD):** Изоляция бизнес-логики в масштабируемой ERP/CRM (склад, финансы, канбан, RBAC), чистый код без циклических зависимостей.
4. **PostgreSQL & Zero-Downtime:** Сложные аналитические SQL-запросы, индексация и проведение миграций схем без простоя пользователей.
5. **Короткий Time-to-Market:** Быстрая и предсказуемая доставка сложных фич в продакшен за счет модульной архитектуры FSD и строгого контроля качества (TypeScript + ESLint).
6. **WebRTC & Телеком:** Облачный софтфон прямо в окне браузера с каскадной переадресацией и WebSockets-журналом звонков.
7. **Мобильная разработка:** React Native (Expo) — полный цикл разработки и публикации в Google Play Console (RPG Tasks).

## 🛠️ Запуск проекта

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка продакшен-бандла (TypeScript + Vite)
npm run build

# 4. Предпросмотр сборки
npm run preview
```

## 🚀 Деплой на GitHub Pages

Проект настроен для автоматической публикации через **GitHub Actions**:

1. Откройте репозиторий на GitHub: [nnspecter/PortfolioLanding](https://github.com/nnspecter/PortfolioLanding).
2. Перейдите в раздел **Settings** → **Pages**.
3. В блоке **Build and deployment** в выпадающем списке **Source** выберите **GitHub Actions**.
4. После пуша в ветку `main` workflow `.github/workflows/deploy.yml` автоматически соберет проект и опубликует его по адресу:
   👉 **https://nnspecter.github.io/PortfolioLanding/**
